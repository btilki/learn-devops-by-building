# Chapter 3 checkpoint

The baseline rejects a score-only record that has severity and treatment but no asset, attack path, owner, residual risk, or review trigger.

The completed checkpoint verifies that registered risks name context, exposure, treatment, residual risk, and owners, and that the selected control portfolio covers the independently required attack paths.

It cannot prove that the residual-risk judgments are wise for a real organization or that unmodeled paths are absent.
