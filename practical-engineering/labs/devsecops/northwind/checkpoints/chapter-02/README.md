# Chapter 2 checkpoint

The baseline rejects a generic attacker story that references unknown flows and an undefined security goal.

The completed checkpoint verifies declared components and flows, required trust boundaries, flow-to-boundary agreement, attack prerequisites, attack-step traceability, known threatened invariants, missing-evidence statements, and coverage of the independently required priority invariants.

It cannot discover unknown architecture, prove assumptions true, predict attacker behavior, or establish objective attack likelihood.
