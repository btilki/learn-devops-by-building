# Chapter 8 checkpoint

The baseline proves that ranking by severity alone displaces an exploitable order-path finding with an unreachable critical library.

The completed checkpoint verifies context-backed vulnerability decisions: exposure, exploitability, harm, owner, treatment, deadline, and exception reasons.

The challenge evaluates `checkpoints/chapter-08/cases/severity-only-decisions.yaml`.

It cannot prove that scanner coverage is complete or that a KEV or CVSS label is a production risk decision.
